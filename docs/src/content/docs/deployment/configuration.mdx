FxEmbed is configured through environment variables (`.env`), Wrangler settings (`wrangler.toml`), and an optional branding file (`branding.json`).

## Environment Variables

Copy `.env.example` to `.env` and configure:

### Domain Lists

These comma-separated lists define which domains route to which realm:

| Variable                      | Description             | Example                                |
| ----------------------------- | ----------------------- | -------------------------------------- |
| `STANDARD_DOMAIN_LIST`        | X/Twitter embed domains | `fxtwitter.com,fixupx.com,twittpr.com` |
| `STANDARD_BSKY_DOMAIN_LIST`   | Bluesky embed domains   | `fxbsky.app`                           |
| `STANDARD_TIKTOK_DOMAIN_LIST` | TikTok embed domains    | `fixtok.example.com`                   |

### Subdomain Feature Domains

| Variable               | Description                           | Example                            |
| ---------------------- | ------------------------------------- | ---------------------------------- |
| `DIRECT_MEDIA_DOMAINS` | `d.`/`dl.` direct media subdomains    | `d.fxtwitter.com,dl.fxtwitter.com` |
| `TEXT_ONLY_DOMAINS`    | `t.` text-only subdomains             | `t.fxtwitter.com`                  |
| `INSTANT_VIEW_DOMAINS` | `i.` Telegram Instant View subdomains | `i.fxtwitter.com`                  |
| `GALLERY_DOMAINS`      | `g.` gallery subdomains               | `g.fxtwitter.com`                  |
| `FORCE_MOSAIC_DOMAINS` | `m.` mosaic subdomains                | `m.fxtwitter.com`                  |
| `OLD_EMBED_DOMAINS`    | `o.` legacy embed subdomains          | `o.fxtwitter.com`                  |

### API Domains

| Variable                | Description           | Example             |
| ----------------------- | --------------------- | ------------------- |
| `API_HOST_LIST`         | FxTwitter API host(s) | `api.fxtwitter.com` |
| `BLUESKY_API_HOST_LIST` | FxBluesky API host(s) | `api.fxbsky.app`    |

### Service Domains

| Variable                           | Description                                 |
| ---------------------------------- | ------------------------------------------- |
| `MOSAIC_DOMAIN_LIST`               | Mosaic image generation service endpoint(s) |
| `GIF_TRANSCODE_DOMAIN_LIST`        | GIF transcoding service endpoint(s)         |
| `VIDEO_TRANSCODE_DOMAIN_LIST`      | Video transcoding service endpoint(s)       |
| `VIDEO_TRANSCODE_BSKY_DOMAIN_LIST` | Bluesky video transcoding endpoint(s)       |
| `POLYGLOT_DOMAIN_LIST`             | Translation service endpoint(s)             |
| `POLYGLOT_ACCESS_TOKEN`            | Translation service access token            |
| `ORCAROUTER_API_KEY`               | OrcaRouter API key (`sk-orca-…`), pasted    |
| `ORCAROUTER_OAUTH_KEY`             | OrcaRouter key from `npm run orcarouter:login` |
| `ORCAROUTER_MODEL`                 | OrcaRouter model id for translation         |
| `ORCA_BASE_URL`                    | Shared OrcaRouter origin (self-hosted)      |
| `ORCA_AUTH_BASE_URL`               | Auth origin override (wins over the above)  |
| `ORCA_API_BASE_URL`                | Inference origin override (wins over the above) |
| `TWITTER_ROOT`                     | Base Twitter/X URL for redirects            |

### Sentry (Error Reporting)

| Variable            | Description                                      |
| ------------------- | ------------------------------------------------ |
| `SENTRY_DSN`        | Sentry Data Source Name (leave empty to disable) |
| `SENTRY_AUTH_TOKEN` | Sentry authentication token for source maps      |
| `SENTRY_ORG`        | Sentry organization slug                         |
| `SENTRY_PROJECT`    | Sentry project slug                              |

## Wrangler Configuration

The `wrangler.toml` file configures the Cloudflare Worker:

```toml
name = "fxembed"
account_id = "YOUR_ACCOUNT_ID"
main = "./dist/worker.js"
compatibility_date = "2026-04-11"
send_metrics = false

analytics_engine_datasets = [
  { binding = "AnalyticsEngine" }
]

[build]
command = "npm run build"
```

### Key Settings

- **`name`**: Worker name (appears in `*.workers.dev` URL)
- **`account_id`**: Your [Cloudflare Account ID](https://developers.cloudflare.com/fundamentals/get-started/basic-tasks/find-account-and-zone-ids/)
- **`compatibility_date`**: Cloudflare Workers API compatibility date
- **`analytics_engine_datasets`**: Remove this block if you don't use Cloudflare Analytics Engine

### Secrets

Some values should be set as Wrangler secrets rather than in `.env` or `wrangler.toml`:

```bash
wrangler secret put CREDENTIAL_KEY
wrangler secret put EXCEPTION_DISCORD_WEBHOOK
```

- **`CREDENTIAL_KEY`**: Encryption key for credential storage
- **`EXCEPTION_DISCORD_WEBHOOK`**: Discord webhook URL for exception notifications

## OrcaRouter

[OrcaRouter](https://www.orcarouter.ai) is an OpenAI-compatible AI gateway that routes
many providers behind one endpoint. FxEmbed can use it for post translation, as an
alternative to the Cloudflare Workers AI binding and the Polyglot service.

There are two independent ways to authenticate. Both end up producing the same kind of
ordinary OrcaRouter API key, and both are configured in `.env`.

### Option 1 — paste an existing API key

Create a key in the [OrcaRouter console](https://www.orcarouter.ai/console), then:

```bash
npm run orcarouter:key -- sk-orca-…
```

This writes `ORCAROUTER_API_KEY` to `.env`. It does not start a login.

### Option 2 — sign in with an OrcaRouter account (OAuth 2.0 + PKCE)

```bash
npm run orcarouter:login
```

This prints an authorization URL, opens nothing on its own, and waits for you to paste
back the code shown on the consent screen (the out-of-band flow — see below). The key it
issues is written to `.env` as `ORCAROUTER_OAUTH_KEY`.

Useful commands:

```bash
npm run orcarouter:status          # show which credential is configured (masked)
npm run orcarouter:logout          # clear the stored PKCE-issued key
npm run orcarouter:models          # list the models the chat selector may offer
```

The key belongs to *you*, not to this project: it is billed to your OrcaRouter account and
can be revoked at any time from
<https://www.orcarouter.ai/console/authorized-apps>. Revoking it deletes every key issued
to this app. FxEmbed reuses the stored key until that happens — it never re-authorizes on
startup, because OrcaRouter caps PKCE-issued keys at 10 per user per 24 hours.

### Choosing a model

`ORCAROUTER_MODEL` selects the model used for translation. The list of valid values comes
from OrcaRouter's live model catalog, filtered to text-capable chat models:

```bash
npm run orcarouter:models          # e.g. orcarouter/auto, openai/gpt-5.5, …
```

The model id is sent verbatim, vendor namespace included. If the configured model is no
longer in the catalog, FxEmbed clears the selection and logs why rather than sending it.
When the catalog endpoint is unreachable, a small verified fallback list is used and
labelled as degraded.

### Self-hosted origins

Authentication and inference use different public origins by default:

| Purpose     | Default                          |
| ----------- | -------------------------------- |
| Auth        | `https://www.orcarouter.ai`      |
| Inference   | `https://api.orcarouter.ai/v1`   |

A self-hosted OrcaRouter deployment can set `ORCA_BASE_URL` to a single shared origin, or
`ORCA_AUTH_BASE_URL` / `ORCA_API_BASE_URL` to override them individually (explicit
overrides win). Non-loopback origins must use HTTPS.

### Why the out-of-band flow

FxEmbed is self-hosted software whose address differs on every deployment, and a
Cloudflare Worker has no long-lived process to host a loopback listener, so the connect
flow uses a displayed code rather than a redirect. `S256` is mandatory for that flow and
is always sent.

## Branding

Copy `branding.example.json` to `branding.json` to customize the appearance and behavior of each domain zone.

Each zone in the `zones` array defines:

```json
{
  "name": "FxTwitter",
  "default": true,
  "domains": ["fxtwitter.com", "twittpr.com"],
  "provider": "twitter",
  "favicon": "https://example.com/favicon.ico",
  "redirect": "https://github.com/FxEmbed/FxEmbed",
  "color": "#6363ff",
  "activityIcons": {
    "default": "https://example.com/icon32.png",
    "svg": "https://example.com/icon.svg",
    "16": "https://example.com/icon16.png",
    "32": "https://example.com/icon32.png"
  }
}
```

| Field           | Description                                                                           |
| --------------- | ------------------------------------------------------------------------------------- |
| `name`          | Display name for this zone                                                            |
| `default`       | Whether this is the default zone (only one should be `true`)                          |
| `domains`       | Domains this zone applies to                                                          |
| `provider`      | Content provider (`twitter`, `bluesky`, `tiktok`)                                     |
| `favicon`       | URL to the favicon served for this zone                                               |
| `redirect`      | Where bare domain visits redirect to                                                  |
| `color`         | Theme color for embeds (hex)                                                          |
| `activityIcons` | Icon URLs at various sizes; `activityIcons` can also be an array for random selection |
